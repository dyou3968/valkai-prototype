# Valkai Self-Serve — Prototypes

Interactive prototypes accompanying a product take-home on whether Valkai
should build a self-serve offering, and for which segment.

**Live site:** https://dyou3968.github.io/valkai-prototype/

**Memo:** https://docs.google.com/document/d/16ViFjazdj24r0xI3PsL2ycmzFEjyoKnbo3Eyjqlr9bM/edit?tab=t.mbjaea9lipl1

## The three prototypes

| # | Surface | What it shows |
|---|---------|---------------|
| 1 | `website.html` — valkai.com | A "Try Valkai" entry point and the purchase journey: plan selection, details, security review, confirmation |
| 2 | `onboarding.html` — app.valkai.com | Six guided setup steps: verify domain, connect a source, set retention policy, invite the team |
| 3 | `admin-console.html` — admin.valkai.com | Ongoing administration: members and seats, connectors, data governance, activity log, plan and billing |

They chain together: an executive buys, an IT admin sets the workspace up, and
that admin operates it afterwards.

## Notes

Prototypes 2 and 3 include a **"Show prototype notes"** toggle in the lower
right corner, which reveals the design rationale for each screen and the
scoping decisions behind the MVP.

Built as static HTML with no dependencies or build step. Meridian Bio is a
fictional mid-size biotech; all figures, pricing, and data are illustrative.
Independent concept exercise, not affiliated with Valkai.
